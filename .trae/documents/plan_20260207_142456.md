# Implementation Plan

## 1. Backend Updates

### `backend/schemas.py`

* Create `AppAdminDetailUpdate` schema for updating app details (name, url, description, etc.) without changing status.

### `backend/main.py`

* Add `PUT /api/admin/apps/{app_id}/update` endpoint.

* Implement logic to update app fields based on `AppAdminDetailUpdate` schema.

* Ensure this endpoint requires admin privileges.

## 2. Frontend Layout & Style

### `frontend/src/views/HomeView.vue`

* Update grid layout to `grid-cols-1 sm:grid-cols-2 lg:grid-cols-4` to ensure 4 cards per row on desktop screens.

* Extract data loading logic into a `loadData` function to support refreshing the list after edits.

### `frontend/src/components/Card_System_v2.vue`

* **Aspect Ratio**: Change image container from fixed height (`h-48`) to `aspect-[4/3]` to maintain the requested ratio while adapting to the new width.

## 3. Frontend Admin Features

### `frontend/src/components/Card_System_v2.vue`

* **Edit Button**: Add a "Pencil" icon button below the existing "Key" button, visible only when `userStore.isAdmin` is true.

* **Edit Modal**: Implement a modal form allowing admins to edit:

  * System Name, URL, Description

  * Developer, Admin Contact, Contact Info

  * Server Location, Category, Scope

* **Logic**:

  * Fetch categories and scopes when opening the modal.

  * Submit updates to the new backend endpoint.

  * Emit a `refresh` event upon successful update.

### `frontend/src/views/HomeView.vue`

* Listen for the `refresh` event from `CardSystem` to reload the app list.
