
# Implementation Plan: Navigation Platform Enhancements

This plan addresses all 5 requirements by refactoring the backend data models and updating the frontend interface.

## 1. Backend Architecture Refactoring

### 1.1 Unified App Model
Merge `PendingApp` and `ApprovedApp` into a single **`App`** table to support better status tracking (Pending, Online, Rejected) and ownership.
*   **Fields**: `id`, `name`, `url`, `description`, `category_id`, `scope_id`, `status` (Enum), `reject_reason`, `owner_id` (User), `icon_data`, `visits`.
*   **Status Enum**: `PENDING(0)`, `ONLINE(1)`, `REJECTED(2)`, `OFFLINE(3)`.

### 1.2 User System
*   **Model**: Create generic **`User`** model with `role` field (`admin` or `user`).
*   **Auth**: Update authentication logic to support both admin and standard users.
*   **Init**: Pre-seed a standard user (`user`/`user123`).

### 1.3 Dynamic Configuration (Categories & Scopes)
*   **Models**: Create **`Category`** and **`AppScope`** tables.
*   **API**: Add CRUD endpoints for Admin to manage these options.
*   **Init**: Seed default categories (Web, Desktop, etc.) and scopes.

### 1.4 Password Manager (Credentials)
*   **Model**: Create **`AppCredential`** table (`user_id`, `app_id`, `username_text`, `password_text`, `note`).
*   **API**: Endpoints to Get/Save credentials for a specific app.

## 2. Frontend Implementation

### 2.1 Admin Dashboard Improvements
*   **Audit Board**:
    *   Add **Preview** button (opens URL).
    *   Add **Reject** button (opens modal to input `reject_reason`).
    *   **Status Filter**: Show Pending apps by default; add history view for Rejected/Approved.
*   **Config Management**:
    *   Add "Category Management" and "Scope Management" tabs.

### 2.2 Website Configuration Fixes
*   **Global State**: Update `App.vue` to fetch config and set `document.title`.
*   **UI Display**: Update `HomeView.vue` or `NavBar.vue` to visibly display the `slogan`.

### 2.3 User Features
*   **User Dashboard**: New page `UserDashboard.vue`.
    *   Lists user's submitted apps with status (Pending, Online, Rejected).
    *   Shows Rejection Reason if applicable.
*   **Submission**: Update `SubmitView.vue` to fetch Categories/Scopes from API.

### 2.4 Password Manager UI
*   **Card Integration**: Add "Key/Lock" icon to `Card_System_v2.vue`.
*   **Interaction**: Clicking icon opens a dialog to view/edit Username/Password/Note (Text format).

## 3. Execution Steps

1.  **Database Reset**: Delete `backend/data/sql_app.db` to apply new schema cleanly.
2.  **Backend Code**:
    *   Modify `models.py` (New tables, unified App table).
    *   Update `schemas.py` (Pydantic models).
    *   Update `main.py` (New APIs, Auth logic).
    *   Update `init_db.py` (Seed data).
3.  **Frontend Code**:
    *   Update `stores/user.ts` (Handle User role).
    *   Update `api` calls.
    *   Modify `AdminDashboard.vue`, `SubmitView.vue`, `HomeView.vue`.
    *   Create `UserDashboard.vue`.
4.  **Verification**: Test all 5 requirements.
